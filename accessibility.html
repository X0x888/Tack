Accessibility

Tack for macOS

Tack uses native macOS controls where practical and is designed to respect system accessibility preferences. Accessibility work is ongoing, especially across the custom note wall and Markdown editor.

Built-in support

  • Light and dark appearances that follow the system setting
  • VoiceOver labels and hints on primary controls
  • Keyboard navigation and shortcuts for common note workflows
  • Reduced-motion behavior that follows the macOS Reduce Motion setting
  • Shapes, text, and icons alongside color for many important states

Tell us where Tack falls short

If you cannot complete a task with VoiceOver, Voice Control, keyboard navigation, reduced motion, increased contrast, or another macOS accessibility feature, email hi@cryptoanalyzer.app. Please include the Tack and macOS versions and the task you were trying to complete.
